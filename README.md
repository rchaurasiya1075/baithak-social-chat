# Baithak — social room chat

Friends ke liye group chat. Ludo (ya koi aur game) ka room code yahin paste hota hai, doosra player copy karke join karta hai.

Isme paise nahi hain. Koi wallet, deposit, withdrawal, stake, pot, ya commission nahi. Sirf chat, challenge card, room code, aur timer.

## Chalana

```bash
npm install
npm start
```

Browser: http://localhost:8787

Doosra phone same Wi‑Fi pe ho to `http://<tumhara-ip>:8787` kholo. Naam daalo, same group me real-time chat chalega.

Server band ho to `index.html` seedha kholo — demo mode, neeche player switch karke flow dekh sakte ho.

## Flow

1. Naam daal ke group me aao.
2. Challenge banao: game + mode (Classic / Quick). Amount nahi.
3. Doosra player Accept kare.
4. Creator room code paste kare. Opponent pe Copy code dikhega.
5. 15 minute ka timer. Khatam hone pe match complete mark karo.

## Legal note

Yeh online social game helper hai, online money game nahi. Stake, entry fee, ya jeet ka payout mat jodo.
